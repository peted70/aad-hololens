# AAD Login on HoloLens 2

![Eye](./images/eye.png)

Here's a short video of the sample app that goes with this post:

[![Demo Video](https://img.youtube.com/vi/7yz7hTNMxBY/0.jpg)](https://www.youtube.com/watch?v=7yz7hTNMxBY)

The code is on GitHub: https://github.com/peted70/aad-hololens

One of the coolest aspects of HoloLens 2 is the iris login as it avoids typing on a virtual keyboard. Although hand-tracked typing is also a useful feature, it can become tiring.

This repository shows how to set up your HoloLens 2 device using AAD credentials and configure the device to use iris login.
